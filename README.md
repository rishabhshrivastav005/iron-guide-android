# Iron Guide

Android gym app: exercise guides for 11 muscle groups (setup, body position, common mistakes, sets/reps, YouTube tutorial links) and a diet planner with calorie/macro calculator and veg, non-veg and vegan meal plans.

## Get the APK
Every push to `main` builds an APK with GitHub Actions and attaches it to a new release under **Releases**.

## Open in Android Studio
Open this folder in Android Studio (Koala or newer) and press Run. The app UI lives in `app/src/main/assets/index.html`; edit it to change exercises or meal plans.
